# AGENTS.md

Правила для агентов — в `CLAUDE.md`, подробные доки — в `docs/` (начни с `docs/README.md`).

**Обязательно для любой модели и любого агента (в том числе субагента):** до первой правки прочитай
`docs/README.md` инструментом `Read`, найди в «Что когда читать» строки под задачу и прочитай эти доки. Хук
`.cursor/hooks/require-docs.sh` (в Claude Code — `.claude/hooks/require-docs.sh`) не даст править файлы, пока доки не
прочитаны. Перед первой правкой напиши строку `Доки: <список прочитанных файлов>`.

Коротко: проект не собираем и не запускаем, код пишем вручную, общаемся по-русски.
